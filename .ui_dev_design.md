# UI design — gen-ai-platform

1. **What is it for?** A place where I and a few game-dev friends type what we want, get images back in seconds, and
   keep them organised by project with the recipe that made each one, so we can find, reuse and tweak them later.
2. **What does the user do 80% of the time?** Type a prompt (often with the sprite preset), generate a few, look at
   them, generate again with a tweak.
3. **Hero surface:** home = a prompt bar across the top (prompt, preset, model switch, project, Generate) with the
   results grid filling the rest of the screen, newest first. Pending images show as placeholders with status in place.
   Size/seed/count/steps sit behind "More". Projects are one click away in the header; the image page opens from the
   grid. Signed out: only a splash with sign-in.
4. **What the system already knows:** the project (default Scratch, or the project page you're on), the model (4B),
   the preset's default size, the seed (random unless given; the used seed comes back and is shown), the user. The
   catalogue (models, presets, sizes) comes from /api/catalogue, never hard-coded.

Dark by default. Image grid squares; pixel-art sprites shown with `image-rendering: pixelated` when scaled up.

## Workflow Requirements

### 1. Sign in
- Data: /api/config (oidc, dev_login, version). Splash: name, one-line pitch, Sign in button.
- Actions: Sign in → /api/auth/oidc/login. Dev only: name field + dev sign-in.
- Empty: n/a. Loading: splash renders at once; button disabled until config loads.
- Error: `?signin_error=not_member` → "Your account isn't on this platform yet — ask Daniel to add you."; `refused` /
  `failed` / other → "Sign-in didn't work, try again." No oidc configured and no dev login → "Sign-in isn't set up."
- Success: lands on home.

### 2. Generate
- Data: catalogue (models, presets, sizes), my projects (for the picker), defaults (4B, Plain, Scratch).
- Actions: prompt (Enter submits, Shift+Enter newline), preset, model switch, project (searchable), More: size, seed,
  count 1–4, steps. Generate.
- Empty: placeholder text in prompt; the preset's hint under it.
- Error: inline under the bar — validation (422), queue full (429), scheduler down (503), with the server's message.
  Prompt kept.
- Success: new cards at the top of the grid immediately with "Queued"/"Generating…" and elapsed time; they turn into
  images when done (poll every 1.5 s while any is pending) or a failed card with the error. 9B selected → a visible
  "Non-commercial licence" note next to the switch.

### 3. Browse my images
- Data: /api/artifacts (mine), paged by `next`.
- Actions: click → image page; Load more.
- Empty: "Nothing yet — describe something above and hit Generate." Loading: skeleton cards.
- Error: banner with retry.

### 4. Inspect an image
- Data: /api/artifacts/{id}; prev/next from the list it was opened from (kept in memory; absent on a direct link).
- Actions: Download (?download=1), Delete (owner only, confirm dialog), Use these settings (home prefilled: prompt,
  preset, model, size, steps, project if mine; keep-seed checkbox), Back, Prev/Next (arrow keys too).
- Recipe panel: prompt, full prompt (collapsible), preset, model + licence (warning if non-commercial), seed, size,
  steps, GPU seconds, worker, project (link), author, created.
- Pending: shows status and refreshes; Failed: shows the error.
- Error: 404 → "Not found, or not shared with you" + back link.
- Success: delete → back to where it came from, card gone.

### 5. Projects
- Data: /api/projects {mine, public} with counts and covers.
- Actions: New project (dialog: name, description, private/public, inline errors e.g. 409 name taken); open; on my
  project page: edit (same dialog), generate bar targeting this project.
- Empty: mine always has Scratch; public empty → "No one has shared a project yet."
- Success: list refreshes immediately; after create, navigate to the new project.

### 6. Someone else's public project
- Same project page, read-only: owner shown, no edit, no generate bar, image pages without Delete; "Use these
  settings" still works (generates into my project).

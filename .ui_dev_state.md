## Workflows
(approved 2026-11-01)
1. Sign in — signed-out splash, sign in through authentik; refused/non-member/failed sign-ins explained on the splash.
2. Generate — on home: type a prompt, pick preset (Plain / Game sprite), model (4B default / 9B with non-commercial
   warning), project (searchable, defaults to Scratch or the project you came from), and under "More": size, seed,
   count 1–4, steps. New images appear at the top of the grid at once and fill in live (queued → running → done/failed).
3. Browse my images — home grid of everything I made, newest first, load more; click opens the image.
4. Inspect an image — large image, recipe (prompt as typed, full prompt, preset, model + licence, seed, size, steps,
   GPU time, worker, project, author, date), download, delete (confirm; owner only), "Use these settings" (back to the
   prompt box prefilled, same seed or new), previous/next within the grid it came from.
5. Projects — list mine and public ones (cover, count, visibility); create (name, description, private/public);
   edit name/description/visibility; open a project's grid; generate straight into my own project from its page.
6. Browse someone else's public project — read-only grid and image pages; no generate/delete controls.

7. Agents (added with phase 3, 2026-11-01) — MCP URL and connect instructions, personal access tokens (create: shown
   once; revoke: confirm), connected OAuth apps (disconnect: confirm).

8. Make more from an image (phase 4a, 2026-11-01) — on the image page: re-roll / change prompt / edit image, 1–4 at a
   time; results appear under "Made from this" and fill in live; a child shows "Made from" with the parent's thumbnail.

9. Sprite versions (phase 4b, 2026-11-01) — Character / Item sprite presets with a magenta/green background choice;
   sprites get a transparent cutout automatically; the image page lists versions on a checkerboard and makes pixel
   sprites (size, colours, square tile or fit), each downloadable; pixel versions deletable (confirm).
